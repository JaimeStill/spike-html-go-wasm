Components

The spike's components, each in every state it has, and reached by the keyboard. The spike's question and evidence.

Code editor

sl-code-editor, a plain-text editor whose Go and JSON are highlighted in the page's palette and scheme, beside a gutter of line numbers.

States

Focus visible

The editor, reached by the keyboard.

File tabs

sl-file-tabs, tabs for a set of files, over the editor showing the active one. The page owns each set: it applies a tab's request to select its file, and the editor's edits, and the tabs follow the set.

States

Focus visible

The tabs, reached by the keyboard.

Console

sl-console, a run's output, exits, and answers as a quiet log. The page owns each log, written here from scripted events with no Go: it applies Clear's request, and the console follows the log.

States

Focus visible

The log, reached by the keyboard.

Timings

sl-timings, the last run's phases as a table in ms, with their total. The page owns each run's timings, recorded here from scripted events with no Go, and the table follows them. It holds nothing to operate, so the keyboard passes it by.

States

Controls

sl-controls, a demo's toolbar: Run, Stop, and Reset, and, where a demo's files are editable, New file, Rename, and Delete. The page owns each state's files and run state, here with no Go: it applies each control's request, a run ending on its own after a moment, and the toolbar follows them.

States

Focus visible

The toolbar, reached by the keyboard.

Go demo

sl-go-demo, live Go composed from the parts above over the page's one runner: its files are the fences written inside it, which read as the page's code before it upgrades. Nothing runs, and no Go loads, until a Run.

States

Focus visible

The demo's toolbar, reached by the keyboard.
